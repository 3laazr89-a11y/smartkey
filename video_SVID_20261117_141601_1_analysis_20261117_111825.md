The emoji search UI layout observed in the video follows a structured, multi-layer arrangement within the keyboard interface. To reproduce this layout, implement the following components and behaviors:

### 1. Search Field
*   **Position:** Located at the absolute top of the keyboard panel.
*   **Alignment:** Full-width horizontal bar. In this RTL (Right-to-Left) configuration, the "Search" placeholder text and magnifying glass icon are right-aligned. An "X" button appears on the left to clear input once typing begins.
*   **Movement:** The field remains fixed at the top of the input area while the keyboard is active.

### 2. Result & Suggestion Area
*   **Initial State:** A multi-row, vertically scrollable grid of emojis occupies the space between the search bar and the category controls.
*   **Active Search State:** When typing begins, the grid is replaced by two distinct rows:
    *   **Emoji Results:** A single horizontal row of relevant emojis appears directly beneath the search bar.
    *   **Text Suggestions:** A row of text-based word completions appears below the emoji results and above the keyboard's top row of letters.
*   **Interaction:** Tapping an emoji result immediately inserts it into the document text field above the keyboard.

### 3. Category Controls
*   **Placement:** A persistent navigation bar is located at the very bottom of the keyboard interface.
*   **Ordering:** Icons are arranged horizontally, representing different categories (e.g., Recents, Smileys, Animals, Food, Activities, Travel, Objects, Symbols, Flags).
*   **Size:** The icons are smaller than the emoji results, optimized for a single-row touch target.

### 4. Keyboard Layout
*   **Placement:** Occupies the lower half of the total keyboard panel, situated between the text suggestions (when searching) and the bottom category bar.
*   **Functionality:** A standard alphabetical layout (Arabic in the video) that provides the input for the search field. 
*   **Transition:** The UI toggles visibility between the full emoji grid and the alphabetical keyboard based on whether the search field is focused.
